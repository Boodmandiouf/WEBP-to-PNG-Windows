# 🖼️ Convertisseur WEBP en PNG Automatique (Windows)

Un script Batch (`.bat`) léger, gratuit et ultra-rapide pour convertir toutes vos images `.webp` au format `.png` en un seul clic. Les fichiers convertis sont automatiquement triés dans un sous-dossier pour garder votre espace de travail parfaitement propre.

---

## 🛠️ Prérequis

Ce script utilise **FFmpeg** pour traiter les images instantanément et sans aucune perte de qualité. 

Si vous ne l'avez pas encore, vous pouvez l'installer en une seconde via **PowerShell** (en mode Administrateur) grâce au gestionnaire de paquets natif de Windows :

```powershell
winget install "FFmpeg (Essentials Build)"
